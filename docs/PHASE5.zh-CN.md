# Phase 5：选定母版后的真实进度

## 已实现：可见区域绑定与六帧 idle 候选

唯一源为用户选定 v3 完整立绘，哈希在 `sources/canonical/manifest.json`。生产入口 `tools/canonical.py` 校验该决定、哈希及脸型锁定；源不存在或改变时直接失败，不从历史候选补位。

`regions.json` 是对实际像素坐标的耳/发梢绑定，不是假装已有完整骨骼或隐藏分层。左/右袖、手、腿及鞋坐标已实际查看。`missingArtwork` 记录尚未画出的内容：抬臂后的背景、完整可弯曲手臂、侧向身体、隐藏衣褶及托腮姿势。未通过新的大动作，更没有从旧脸/身体拼接回用。

`build_idle.py` 从高清源计算六个原生姿势，微呼吸的上身/头脸保持刚性平移；位移在鞋领上方归零。耳尖与发梢使用各自绑定和轻微滞后。所有帧使用同一相机，不逐姿势或逐脸归一化。原生格仍是 192×208；头顶约 12 px 留白为后续轻跃预留，不以新增分辨率虚报。

每帧只从高清源进行一次几何求值，使用 3 倍覆盖积分后统一末端缩采样；不反复加工上一张低清帧。没有 RGB 步长量化，没有生成新脸。输出是 1536×208 的单行 idle 开发条，**不是可安装的 1536×2288 完整图集**。

六帧时长为 1680/660/660/840/840/1920 ms，总周期 6600 ms。第一帧与最后一帧相同，有意留安静停顿。没有“每格必须独立”的伪要求；没有长闭眼，没有伪造宿主不具备的短眨眼或高帧率。表情保持选定母版，不把小尺寸肤色闪烁当状态表达。

## 透明度清理的真实边界

生成母版含 4177 个远离绘制主体、alpha≤8/255 的散点，累计移除 alpha 为 4971。仅清理这些散点和原本完全透明处的 859 个非零 RGB 像素；alpha>8 的原绘制 RGBA 逐像素保持不变，并保留邻近绘制内容 4 个源像素范围的淡边缘。不是对角色做硬阈值抠图。原始源文件未写回，脸型未改变。暗/亮背景共同相机对照已实际查看。

## 否定证据与修正

1. 第一轮鞋领仍受腿部位移影响，且发梢坐标场可以靠近鞋部；最低脚底不变不足以证明鞋正确。现改为整鞋坐标精确固定，腿部过渡在 y=1000 结束，鞋领保护从 y=1015 开始。
2. 硬隔离边界产生较大的局部形变导数，改为保护区内严格零影响、外部 24 源像素平滑退让。耳尖峰值从 0.24° 收敛到 0.20°，保留既定“克制”的范围。全部六姿势的采样 Jacobian >0.95；这只证明有界形变没有折叠，不是漂亮/自然的证明。
3. 前一提交 GitHub 失败发生在 PNG 字节比较。当前 Windows PNG 编码使用 zlib-ng；文件封装字节不是像素。已用逐张解码像素＋JSON 的重建比较修正，并在 GitHub 运行 37758168084 通过。检查没有取消，改成了内容检查。新 idle 的 WebP/GIF 解码帧及真实停留时长也加入同一比较。

## 独立验收页

默认只播放选定母版的 idle 候选，左侧固定第 1 帧、右侧真实停留时间。可选 80/113/192/224 px、亮暗/网格、暂停/重播、单帧检查、减少动态。重绘仅在姿势改变时发生，使用下一帧截止时间调度；暂停、减少动态、页面隐藏时停止计时调度。它不是宿主性能优化，不创造补间帧。

人工视觉认可仍待完成。只有 idle 当前可供播放，failed/waiting、其他六状态、16 方向、完整分层/大动作、状态切换、实际宿主加载与性能均未完成或未证明。不可安装开发条替代完整宠物，不修改已安装宿主。

## 禁止旧构建/安装入口误回退

检查发现仅锁定新 idle 的源仍不够：历史 `build.py` 默认输出 `pet/`，旧 `install.ps1` 普通调用仍可能安装否决的 Phase 3。现已关闭这两个隐式入口。历史构建必须明确 `--historical-phase3 --out work/<隔离子目录>`，源/候选/正式输出目录和真实安装目录不能作为输出。

普通安装直接拒绝，因为新 v3 尚无获认可的完整图集。历史安装只用于显式 `-HistoricalRegression`、明确指定的仓库 `work/` 隔离目标和备份目录，拒绝默认真实安装路径、越界路径和现存重定向路径。`-Baseline` 保留为用户明确需要时的归档基准恢复，不是当前成果。测试在独立 fixture 中验证拒绝默认安装、WhatIf、备份、幂等、错误哈希拒绝和恢复，未触及真实安装。

当前本地 31 项 Python、13 项 Node 测试通过。idle 提交 `6550d52` 已在 GitHub 运行 37762097130 通过，包含逐解码的 38 项重建内容验证；安装入口防回退变更需由其自己的后续 CI 验证，不混用上一提交的结果。
