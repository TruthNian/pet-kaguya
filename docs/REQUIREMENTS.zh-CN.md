# 完整目标与验收账本

目标仍是解决所有已发现问题、尽可能大幅改善本地 Pet Kaguya；不是仅修两个表情或做静态展示。用户已确认轻柔含蓄、原图像素＋程序化动画、兼容图集＋独立验收页，不修改安装宿主。

质量顺序：角色/结构正确 → 状态表达 → 动作自然与适量 → 实际尺寸清晰 → 性能与制作效率。前者不能被后者抵消。可运行基准不等于形象几何真值。

最新用户决定：完整母版选定canonical-v3，原样归档于 `sources/canonical/`；脸型锁定，禁止程序变形修脸及回退否决拼接版。用户选择保留正面轻小步、接受克制摆幅，起落“我觉得还行”仅作为继续打磨基础。现在又选择暂保留托腮/合手的保持时序、继续优化结构，不扩展独立宿主；实际手形/袖褶与全部动作自然度仍pending。现有九状态与16视线是完整覆盖开发验收图集，不是已通过的发布版。腿/眼/手臂层均估计；旧腿中性非无损失败保留，当前腿v2/眼中性精确不证明原画层恢复或边缘自然。保留宿主边界，不因覆盖格齐全而宣称帧率、分辨率、接触、过渡或性能全部修复；旧试作只作失败证据。

此前review合成v3在完整旧袖移除上，恢复2,931个已知母版发丝RGBA，未知内部估计RGB/alpha边界连续性；490条实际相邻边把已知约束接入求解。直接复制和腐蚀后留下隔离环的失败均保留，不采用上轮新生成发丝材料。该发丝处理在当前v4继续保留；完整发束拓扑/接缝、两掌体积/袖褶衔接、入场退场及小尺寸表达仍未解决，R06/R13不得转成“已完成”。全局开发图集已同步，纹理解码内存不变。

三个前轮手袖试验仍未采用。此前同坐标检查纠正诊断：部分指尖异常是合成遮罩裁切，不是原画解剖。当前动作/全局开发图集仍为合成v4，仅取回原素材下方手掌轮廓，不缩放手；母版仍锁定v3。本次连续袖面候选独立展示，未进入动画；逐点绿色选区漏掉深褶线的斑驳失败已保留。母版本有直线/三角阴影，不能仅凭棱角认定错误；任意补片切断褶线才是已观察到的制作缺陷。两份GIMP真实工程已保存/重开，可见RGBA与各自受控结果一致，透明隐藏RGB归零并非全字节不变；CI查归档哈希/导出证据，不运行编辑器。袖口/外轮廓对新褶线的衔接、其他手形、关节层、过渡及R06/R13仍未通过，详见PHASE5-STATES最新章节。

## 验收门槛

1. 静态：Phase 4 拼接试作和程序修脸失败。用户选择完整 AI 生成母版 v3，脸型门槛已明确锁定；其他动作姿势的遮挡、衣饰与结构仍待建立/验收。不得回退到表中历史试作。
2. 动作：按宿主离散帧/时长观看，验证接缝、状态切换、支撑、遮挡与线条稳定；不能用静态测试替代。
3. 全局：所有九状态与十六方向、全部实际尺寸、亮暗/网格、长时克制感；审查是否新增退步。
4. 工程与交付：源、生成结果、测试、公开仓库一致；哈希保护安装与回退；真实宿主选择/加载仍需直接证据。

这些门槛未全部满足前，目标保持未完成。宿主限制必须保留为未解决边界，不改名为“彻底修复”。若要超出边界，先向用户确认。
