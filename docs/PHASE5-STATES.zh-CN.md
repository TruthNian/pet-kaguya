## 第一性原理与五步工作法的具体作用

1. 质疑要求：角色不是每状态独立插画。真正应守恒的是同一角色的头脸/身体、取景和装饰；手遮挡下颌是合法遮挡，不等于可以重画下颌。宿主的时间槽与三轮回退是事实，不能用更快的演示视频替代。没有“每格必须不同”的要求。
2. 删除错误路线：不整张采用生成输出，不复用旧错误脸/身体，不用淡入淡出伪装手臂中间姿势。关闭普通安装旧 atlas 的隐式入口。
3. 简化实现：一个不可变 v3、一个相机、明确的缺画补片；公用原始高分辨率取样及行输出。口眉、手臂各自有严格边界，不把“共用头部”误当完整身份一致性证明。
4. 优化流程：先查看真实坐标与连接，再做补片；实际尺寸对照复用已经算出的帧，不为每个 CSS 尺寸重复求值；播放器只在真实姿势边界重绘、按需解码候选。没有由此推断原生 CPU/GPU/FPS 改善。
5. 最后自动化：守卫生成源 SHA、补片外逐像素相等、保护眼睛/下颌/衣服、固定整鞋、八姿势坐标场、真实三轮截止与回退、全部保存像素重建一致。自动化只证明这些具体条件。

## 否定证据

- failed 第一版口线区域与左眼保护范围相交，构建被拒绝。改为沿原口线实际位置的带缺口多边形，**未缩小眼睛保护范围、未放宽检查**。
- 生成的失落口线比原笑容短，未满足提示词中的同宽要求；记录为未证明的提示约束，不把它写成精确局部编辑完全成功。眉嘴候选是否合适需要视觉判断。
- waiting 衣袖/隐藏背景只针对这一个已画关键姿势。不能据此宣称已经有完整肘腕骨骼、举手背景、可弯曲衣褶、侧身或自然步态。
- failed 上身轻下沉不是有完整关节的鞠躬或坐下。坐姿身份错误路线被删除，但自然度和小尺寸状态辨认仍需审查。
