# 验收记录

## 可以复核的证据

- `baseline/phase2/manifest.json`：原样基准哈希与字节数。
- `pet/build.json`：候选哈希、源哈希、参数方法、逐帧相位、真实时长、RGB 量化边界；无机器绝对路径。
- `qa/comparison.json`：两版本经同一个审计程序测量的结构、透明度、循环帧差和方向帧差。
- `qa/comparison-{80,113,192,224}px.png`：各尺寸第一帧静态采样模拟，不是实机截图。
- `qa/candidate-*.gif`：按实际慢 idle/各状态周期播放的离线预览；GIF 不包含宿主的三轮回退或鼠标优先级。
- `viewer/`：离线本地对照页，默认真实时长、三轮回退，实验循环和实验平滑采样单独标明。

## 未证明 / 未测量

- 未修改、自动操控或重启已安装宿主；本机当前浮层的实际来源/选择和热加载结果没有自动确认。
- 原生 CPU/GPU 占用、耗电、实际显示帧率没有测量；浏览器显示的是 Canvas 绘制调用 CPU 耗时，不包括 GPU 合成、解码和操作系统呈现。
- 64 相位非折叠检查是有界采样，不是对任意参数的数学证明。
- “8 个独立帧”不是“8 个自然姿势”的证明；跑步、跨状态过渡和长期可爱感仍需人类审美验收。

## 依赖与协议来源

本机构建使用 NumPy 2.5.2 / Pillow 12.3.0（固定在 `requirements.txt`）；包元数据来自 [NumPy](https://pypi.org/project/numpy/2.5.2/) 和 [Pillow](https://pypi.org/project/pillow/12.3.0/) 的官方发行页。Python 3.12、Node 22+，测试不需要外部模型或 API 密钥。
