# 质量目标与五步工作法

本项目中的五步法：质疑需求 → 删除 → 简化/优化 → 加快反馈 → 自动化。顺序不可颠倒。

## 当前阶段：Phase 5；Phase 4 是失败历史

Phase 5 当前进度见 `PHASE5-STATES.zh-CN.md`：唯一v3源已有九动作/16眼内方向完整覆盖开发图集；新failed嘴线仅获开发基础批准，其他动作/结构/全局自然度仍待。原生格/时长、局部保护与重建已检查；这不是完整分层或已安装发布。`PHASE5.zh-CN.md`是先前idle/source工作，不能把适合小幅idle的坐标场当成所有姿势骨架。

全局验收现明确区分理想单行时钟和本机链式计时：选择依次为拖拽覆盖、悬停jumping、底层任务；仅有效依赖变化才首格重启。方向对象身份/移除也可能重启；迟到回调不追赶漏槽。独立中断验收区用当前图集显示硬切，不是新宿主或原生性能录像。手袖造型、空中恢复/手势进入退出、80px弱提示、长时观看与正式交付仍未完成。

最新决策：用户选定完整生成立绘 canonical-v3，已原样存入 `sources/canonical/`。脸型锁定；不再强接旧身体、不再程序变形修脸、不回退到已否决试作。下一步是从这一张完整角色建立可信的遮挡/分层及轻柔动作。以下提到原始头部拼接和审阅手势修补的内容是失败历史，不是当前制作方案。

全量目标与验收门槛见 `REQUIREMENTS.zh-CN.md`；当前静态实现见 `STATIC-REVIEW.zh-CN.md`。Phase 3 是工程候选，不是视觉通过版本。

Phase 4 静态试作也已被用户否决：机械共享头部并没有统一完整身体结构，不能作为动画基础。这次失败属于证据，不应以局部测试通过淡化。下一步首先建立完整一致母版/分层与遮挡依据，不再把不同身体强接一张头当成统一角色模型。

生成关系应是：角色结构 → 合法姿势/表情 → 时间变化 → 栅格采样 → 宿主显示。每行一张母图只约束行内，不能替代统一角色结构。Alpha 相同不能证明内部五官/下颌正确。连续函数周期性不能证明离散帧循环自然。

先依据用户确认的原始正面形象建立静态结构，再验证表情和手部遮挡，再制作动作。第一轮压眼皮试验读作困倦，已删除；低头 review 母图接正面头会留下旧脸残片，已换成头颈位置匹配的原始审阅手势。这些否定结果不能因为测试容易通过而略过。

不再要求每帧像素唯一：有意停顿可以重复帧。删除的是无依据的拼接和变形，不是状态表达。加快的是单因素验证周期，不是角色播放速度。自动化只守住确认过的局部规则，不替代人类审美验收。

## 第一性原理

桌面宠物的任务不是展示最多动作，而是在小尺寸、余光观看、长时间运行的条件下，提供稳定的角色身份、适量的生命感、可理解的状态。可爱不是像素差小，流畅不是把 timer 换成 rAF，自然不是持续晃动。

角色连续性需要同一套解剖比例、衣饰纹理和锚点。运动应是同一个对象随时间变形，而非无关图画轮流出现。身体、头、耳尖和发梢存在不同响应时延；脚接触地面时不能随微呼吸漂移。状态表达应优先使用清晰姿势，不能依赖 11 × 11 px 的局部色差。

## 1. 质疑需求

- **分辨率**：当前兼容协议要求 192 × 208 的单帧和 1536 × 2288 的整图。扩大画布不能直接安装；插值放大不增加绘画细节。小尺寸的采样质量是宿主问题，不伪称已由图集解决。
- **帧率**：宿主规定帧数与时长，idle 六帧共 6.6 s。目标是降低可见位置跳变，并按真实时长设计，而非虚构 60 FPS 原生动画。
- **轻柔含蓄**：用户已明确选择原图像素＋程序化动画，不修改安装的宿主，只改善兼容图集和独立验收播放器。

## 2. 删除

删除闲置状态长时间闭眼、处理状态困倦脸、失败状态突然坐下、方向状态全身大幅转向、重复静帧掩盖跳变的优化指标。不新增粒子、额外道具或功能。

## 3. 简化 / 优化

Phase 3 曾使用每行固定母版和连续位移场；这未统一各状态结构，failed 的供体拼接还造成错误下颌。该方案不得作为已验收方法继续套用。Phase 4 先分离共同头部、身体姿势、表情编辑和前景遮挡。不能通过镜像把月饰放错侧，也不能把正面头强贴到不同投影。预乘 alpha 采样仍可防暗边，但是否需要采样、是否软化线条，必须单因素比较。

## 4. 加快反馈

自动生成所有状态的实际时序、亮/暗背景、80/113/192/224 px、循环接缝和方向序列。原生行为模拟与可控实验播放器分开标明。任何审美判断要经过实际大小观看，不能只看放大的拼图。

## 5. 自动化

固定依赖、源图哈希、动画参数、可复现构建、无网络验收、结构/透明度/运动场折叠/锚点/循环接缝测试和 GitHub CI。只有结构测试可自动通过；“足够可爱”仍需人类观看，不以指标替代。

## 本轮不能由图集修复的宿主限制

固定时长和帧数、pixelated 缩放、三次动作后回 idle、部分状态被 pointer-look 覆盖、无帧间插值、无事件/骨骼源资产协议。独立开发预览不是新桌面宠物，也不能证明已安装宿主改变了这些行为。

## 已撤回的先前判断

文件减小不等于内存减小；平均帧差下降不等于自然；三个失败姿态重复成八帧不等于补间；idle 闭眼并不短；方向投影面积不同并不单独证明比例错误。新的结果也必须接受相同的证据标准。
